## 我们为谁解决什么问题？

**意向客户：** 一级/二级市场研究员、战投与战略、财经媒体与调查记者、高风险决策岗（合规、政府事务、高管办公室）、需要**快速拆穿叙事**的内容创作者。

| 痛点 | Truth Decoder 的回应 |
|------|----------------------|
| 通稿与公关话术**信息量大、真话少、结构绕**，读完仍不知道谁赢谁输 | 把「表层叙事 → 机制 → 代价」拆开，并给出可引用的**裁定式结论** |
| 普通摘要丢掉**因果链、利益相关方与未说之词** | **利益相关方链**、**叙事杠杆**、**认识论缺口（可验证性）** 等结构化输出 |
| 投研与memo需要**可分享、可归档**的成品 | **导出 PDF / 图片**，方便进研报、备忘录与社交媒体 |
| 全球市场材料中英混杂，团队口径不一 | 界面与流程支持 **中文 / English** 切换，服务跨境叙事 |
| 「AI 胡说」导致误判 | 强调**锚点原文**、**核验清单**（如监管披露、WARN、交叉信源）与**可验证性提示** |
| 深度分析不能停在「一段话总结」 | **双栏深读**：原文语义高亮 + **Deep Insight**（表层伪装 / 核心机制 / 收割代价） |
| 卷宗读完还想追问细节 | **Pro Terminal**：在已确认的硬事实之上，用**指令式追问**继续「审讯」叙事 |

**说明：** 产品输出用于**辅助研究与表达**，不构成投资建议；重大决策请结合原始材料与专业顾问意见。

## 亮点功能（逐项说明）

### 1. Secure Gate 指挥台：粘贴即拦截

- **一句话：** 左侧大面积输入区，占位提示「Paste the official narrative here…」，一键 **INITIALIZE ENGINE** 启动解码。
- **情报流：** 右侧展示历史解码卡片，每条用**冷峻的一行裁定**抓住眼球（便于扫一眼判断「这篇值不值得深读」）。
- **状态感：** 顶栏 **COMMANDER_ACTIVE** 等状态，传递「引擎在线、可执行任务」的心理暗示。
- **双语：** **CN / EN** 切换，覆盖中文通稿与国际英文叙事。
- **Pro 权益提示：** 顶区说明 **Unlimited dossier generations** 与 **ingest 管线无限解析**，方便用户理解付费价值。

![指挥台与情报流](https://raw.githubusercontent.com/liudalao2003-collab/truth-decoder/main/docs/screenshots/01-home-secure-gate.png)

---

### 2. 终局裁定（The Ultimate Verdict）与专业导出

- **裁定式输出：** 中央卡片给出**一句话战略裁定**（例如将裁员与 AI 叙事还原为「劳动力向资本的价值转移」这类**可辩论、可引用**的论点）。
- **导出：** **EXPORT PDF**、**EXPORT IMAGE**，直接服务研报附件、投资备忘录与社交传播。
- **PRO 标识：** 与订阅能力联动，便于对外展示**商业化与专业版**定位。
- **会话选项：** 支持 **Include terminal（this session）** 等扩展能力，把「长卷宗」与「终端追问」串在同一会话里。
- **导航：** **INDEX** 回到索引或列表，符合「材料很多但要快速跳转」的工作流。

![终局裁定与导出](https://raw.githubusercontent.com/liudalao2003-collab/truth-decoder/main/docs/screenshots/02-verdict-export.png)

---

### 3. Intel Signature：对抗式素描 + 一页读懂 + 雷达体征

- **一页读懂（Intel Rationale）：** 自动生成高管级**一页纸逻辑**，先回答「到底在发生什么」。
- **叙事杠杆（Narrative leverage）：** 说明叙事如何**框定公众情绪**（例如恐惧、不确定感）以服务特定利益。
- **利益相关方张力（Stakeholder tension）：** 点名**谁承担代价、谁收割收益**（如人力预算转向资本开支）。
- **行动压力（Action pressure）：** 评估叙事是否在**迫使读者**做出仓促反应（职业风险、交易行为等）。
- **认识论缺口 / 可验证性（Epistemic gap）：** 标出**关键数字或断言**是否缺乏官方或可追溯来源，降低被二手消息带偏的概率。
- **Intel 雷达图：** 多轴分数一图对比**叙事强度、张力、可验证性、行动压力**，适合横向对比多篇材料或同一主题下的多次解读。

![Intel Signature 情报体征](https://raw.githubusercontent.com/liudalao2003-collab/truth-decoder/main/docs/screenshots/03-intel-signature.png)

---

### 4. 利益相关方看板 + 冲突链 + 核验清单 + 本地笔记

- **冲突链（Conflict chain）：** 用**从左到右的因果链**展示「决策方 → 受损方 → 间接受益行业 → 更广泛群体」，把新闻读成**结构图**。
- **利益相关方表：** 每行包含主体、角色、影响与**锚点（Anchor）**——把判断钉在**原文或可追溯表述**上，而不是空泛形容词。
- **核验清单（Verification checklist）：** 给出**可执行步骤**（例如 WARN、SEC 10-Q/10-K、劳工部门备案、投行报告溯源），并带**完成进度**，把「我觉得不对」变成「下一步查什么」。
- **My Notes：** 支持在调查过程中做笔记；说明**仅本浏览器存储**时，强调**敏感调研的隐私边界**（具体存储策略以产品实现为准）。

![利益相关方与核验清单](https://raw.githubusercontent.com/liudalao2003-collab/truth-decoder/main/docs/screenshots/04-stakeholder-verification.png)

---

### 5. 原文未删档 + 语义高亮 + Deep Insight

- **SOURCE_MATERIAL_UNTOUCHED：** 强调在**未改写的原文**上工作，便于审计与复核。
- **语义高亮：** 对「组织变革」「为 AI 项目供血」等**关键句**高亮，提示读者**谈判点在哪里**。
- **Deep Insight 弹层：** 结构化呈现 **[表层伪装] / [核心机制] / [收割代价]**，把同一段官方话术翻译成**财务与权力语言**。
- **战略综合：** 右侧可生成**框架化 thesis**（例如多轴「绞杀」式竞争叙事），把碎片化新闻**抬升到可讨论的战略模型**。
- **交互：** 支持点击高亮再次关闭等操作，适合**长时间屏幕阅读**场景。

![原文深读与 Deep Insight](https://raw.githubusercontent.com/liudalao2003-collab/truth-decoder/main/docs/screenshots/05-deep-insight-source.png)

### 6. Pro Terminal：基于硬事实的指令式追问

- **定位：** 在系统已汇总的**硬事实**之上，用终端形态做**高密度追问**，而不是泛泛聊天。
- **交互：** **Enter directive to interrogate…** 强调**指令感与可控性**；适合分析师连续下钻。
- **Pro 价值：** 顶栏说明 **Unlimited terminal interrogations** 等，面向**高频研究用户**与**无上限额度**需求。
- **会话清理：** **CLEAR** 等控制，便于在长会话中**重置上下文**。

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 / 全栈 | Next.js 16（App Router）、React 19、TypeScript、Tailwind CSS 4、Framer Motion |
| 数据与鉴权 | Supabase（`@supabase/ssr`、`@supabase/supabase-js`） |
| 缓存 / 限流（可选） | Upstash Redis |
| 支付（可选） | Stripe |
| AI | 通过环境变量配置的模型 API（如 DeepSeek，见 `.env.example`） |
| 其他 | Zod 校验、部分 API 使用 Edge Runtime；导出相关依赖 `html2canvas` 等 |

## 快速开始

### 环境要求

- Node.js 20+（与 `package.json` 中 `@types/node` 一致即可）
- 包管理器任选：`npm` / `pnpm` / `yarn`

### 安装与本地运行

```bash
git clone https://github.com/liudalao2003-collab/truth-decoder.git
cd truth-decoder
npm install
cp .env.example .env.local
# 编辑 .env.local，填入密钥（切勿将真实密钥提交到 Git）
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

### 构建

```bash
npm run build
npm run start
```

### 代码质量

```bash
npm run lint
```

## 环境变量

复制 `.env.example` 为 `.env.local` 后填写。**密钥只放服务端或受控环境，不要写进前端或公开仓库。**

| 类型 | 变量（节选） |
|------|----------------|
| Supabase | `NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_ANON_KEY`、`SUPABASE_SERVICE_ROLE_KEY`（服务端写 `profiles` 等，缺失时可能出现付款成功但未升级 Pro） |
| 鉴权 / 入库 | `INGEST_TOKEN`；浏览器可走 Cookie，脚本可带 Bearer 调用 v1 接口 |
| AI | `DEEPSEEK_API_KEY`（情报体征与卷宗等；与 Vercel 部署时需与本地一致） |
| 站点 | `NEXT_PUBLIC_SITE_URL` |
| Stripe | `STRIPE_SECRET_KEY`、`STRIPE_WEBHOOK_SECRET`、`STRIPE_PRICE_ID_PRO` |
| 管理后台 | `NEXT_PUBLIC_ADMIN_EMAIL` |
| 可选 | `UPSTASH_REDIS_REST_URL`、`UPSTASH_REDIS_REST_TOKEN`、`CRON_SECRET`、`DOSSIER_FREE_MONTHLY_LIMIT` 等 |

完整说明见 [`.env.example`](.env.example)。**若在 Vercel 部署，请在 Project → Settings → Environment Variables 中同步上述变量。**

## English

**Truth Decoder** is a narrative-intelligence workbench for dense official text—PR filings, corporate statements, and market stories. It goes beyond summarization: **Intel Signature** metrics, **stakeholder conflict chains**, **verification checklists**, **Deep Insight** layers on untouched source text, **verdict-style outputs** with **PDF/image export**, and an optional **Pro Terminal** for directive-driven follow-ups. Bilingual **CN/EN** UI.

- **Stack:** Next.js (App Router), React, TypeScript, Supabase, optional Stripe and Upstash Redis.  
- **Configure:** Copy [`.env.example`](.env.example) to `.env.local`. Never commit secrets.  
- **Run:** `npm install` → `npm run dev`.  
- **Screenshots:** [docs/screenshots](https://github.com/liudalao2003-collab/truth-decoder/tree/main/docs/screenshots) (also embedded above via Raw URLs)
